# Tesera

🧩 Tesera это движок для ERP-систем: готовый интерфейс, набор модулей и единая дизайн-система в одной коробке. Ставишь в проект и сразу получаешь рабочую админку, а не пустой каркас.

🎯 Смысл в том, чтобы не собирать ERP с нуля. Базовые вещи (деньги, люди, проекты, отчёты, справочники) уже готовы, а всё, что ты добавляешь сверху, само выглядит в едином стиле, потому что это движок, а не разовый проект.

## 🚀 Запуск

```bash
pnpm install
pnpm dev
```

🌐 Открой http://localhost:4000, это и есть готовая ERP.

## 🧱 Что внутри

- 📦 `packages/core`: ядро движка (сущности, данные, права, события).
- 🎨 `packages/ui`: дизайн-система (карточки, таблицы, графики, формы).
- 🖥️ `apps/erp`: само приложение на Next.js (дашборд и разделы).
- 🧪 `examples/inventory`: маленький пример работы ядра без интерфейса.

## 🛠️ Как добавить своё

✍️ Новый раздел делается в три шага:

1. 📁 Создай страницу в `apps/erp/app/(erp)/<раздел>`.
2. 🧭 Добавь пункт меню в `apps/erp/src/tesera/registry.ts`.
3. 🗃️ Опиши данные модулем в `apps/erp/src/tesera/modules/`.

♻️ Бери готовые компоненты из `@tesera/ui` и не пиши стили вручную, тогда новый раздел останется в общем стиле.
